1. Number Systems & Digital Logic / संख्या पद्धति और डिजिटल लॉजिक

Number systems / संख्या पद्धतियाँ

SystemBaseDigits
Binary / द्वि-आधारी20, 1
Octal / अष्ट-आधारी80–7
Decimal / दशमलव100–9
Hexadecimal / षोडश-आधारी160–9, A–F (A=10 … F=15)
  • Decimal → binary: divide by 2 repeatedly, read remainders bottom to top. दशमलव → बाइनरी: बार-बार 2 से भाग दें, शेषफल नीचे से ऊपर पढ़ें।
  • Binary → octal: group 3 bits; binary → hex: group 4 bits (from the right). बाइनरी → ऑक्टल: 3 बिट के समूह; बाइनरी → हेक्स: 4 बिट के समूह।
  • Fraction: 1011.1101₂ = 8+2+1 + 0.5+0.25+0.0625 = 11.8125
  • 1's complement = flip all bits; 2's complement = 1's complement + 1. Negative numbers are stored in 2's complement. ऋणात्मक संख्याएँ 2's complement में संग्रहित होती हैं।
  • Range of n-bit signed (2's complement): −2n−1 to 2n−1−1.
  • Booth's algorithm = multiplication of signed binary numbers. बूथ एल्गोरिदम = बाइनरी गुणा।
  • Error detection: parity bit, checksum, CRC. Error correction: Hamming code.
  • Codes: ASCII (7-bit, 128 chars), Extended ASCII (8-bit, 256), Unicode (supports Hindi and all languages), BCD, Gray code.

Logic gates / लॉजिक गेट

GateExpressionOutput is 1 when…
ANDA·Bboth inputs 1
ORA+Bany input 1
NOTA'input is 0
NAND(A·B)'any input 0 — universal gate
NOR(A+B)'both inputs 0 — universal gate
XORA⊕Binputs are different (odd number of 1s)
XNOR(A⊕B)'inputs are same
  • NAND and NOR are universal gates — any circuit can be built from them alone. NAND और NOR यूनिवर्सल गेट हैं।
  • De Morgan: (A·B)' = A' + B'  and  (A+B)' = A'·B'. Used to simplify Boolean expressions. बूलियन व्यंजकों को सरल करने में उपयोगी।
  • Don't-care condition: input combination whose value does not affect the output (used in K-map to simplify).
  • Half adder: Sum = A⊕B, Carry = A·B. Full adder adds 3 bits (A, B, Cin).
  • Multiplexer: 2n-to-1 needs n select lines (8-to-1 → 3). Decoder: n inputs → 2n outputs.
  • Flip-flops: SR, JK, D, T (store 1 bit). Combinational circuit: output depends only on current input; sequential: also on past state (has memory).
  • PLA = Programmable Logic Array. ROM types: MROM, PROM, EPROM, EEPROM.

2. Computer Fundamentals & Memory / कंप्यूटर के मूल सिद्धांत और मेमोरी

  • Generations: 1st vacuum tube, 2nd transistor, 3rd IC, 4th microprocessor (VLSI), 5th AI. पहली पीढ़ी वैक्यूम ट्यूब, दूसरी ट्रांजिस्टर, तीसरी IC, चौथी माइक्रोप्रोसेसर, पाँचवीं AI।
  • CPU = ALU + Control Unit + Registers. Von Neumann architecture: program and data stored in the same memory.
  • Memory hierarchy (fast → slow, small → big): Registers → Cache → RAM → Secondary storage (HDD/SSD). रजिस्टर → कैश → RAM → हार्ड डिस्क।
  • RAM: volatile (data lost when power off). ROM: non-volatile. SRAM (cache, faster, costly), DRAM (main memory, needs refresh).
  • 1 KB = 1024 B, 1 MB = 1024 KB, 1 GB = 1024 MB, 1 TB = 1024 GB. 1 byte = 8 bits; 4 bits = nibble.
  • Cache mapping: direct, associative, set-associative. TLB is an associative cache for page table entries.
  • Input devices: keyboard, mouse, scanner, OMR, OCR, MICR, barcode reader. Output: monitor, printer, plotter, speaker.
  • Software: System software (OS, compiler, assembler, interpreter, utilities) and application software. Compiler translates the whole program; interpreter line by line; assembler converts assembly to machine code.
  • Booting: BIOS/POST → bootloader → OS loaded into RAM. Cold boot = power on; warm boot = restart.
  • Instruction cycle: Fetch → Decode → Execute.

3. C Programming / C प्रोग्रामिंग

Basics

  • C was developed by Dennis Ritchie at Bell Labs (1972). Case-sensitive; execution starts at main(). C भाषा डेनिस रिची ने बनाई; क्रियान्वयन main() से शुरू होता है।
  • Data types: int (2/4 B), char (1 B), float (4 B), double (8 B). Format specifiers: %d, %f, %c, %s, %lf, %x.
  • Operators: arithmetic (+ − * / %), relational, logical (&& || !), bitwise (& | ^ ~ << >>), assignment, ++/−−, ternary (?:), sizeof.
  • Integer division: 7/2 = 3; 7%2 = 1; 7/2.0 = 3.5.
  • Operator precedence (high → low): () [] → unary (++ −− ! ~) → * / % → + − → shift → relational → == != → & → ^ → | → && → || → ?: → =
  • Storage classes: auto, register, static (keeps value between calls), extern.
  • Loops: for, while (entry-controlled), do-while (exit-controlled, runs at least once). break exits loop; continue skips to next iteration.

Arrays, pointers, functions, strings

  • Array index starts at 0; array name is the address of the first element. int a[5] → a[0]…a[4].
  • Pointer stores an address: int *p = &x; *p gives value, p gives address. p+1 moves by sizeof(type) bytes. पॉइंटर पता संग्रहित करता है; *p मान देता है।
  • Call by value (copy) vs call by reference (pass pointer, original changes).
  • String = char array ending with '\0'. Functions: strlen, strcpy, strcat, strcmp (string.h).
  • malloc(size) allocates memory (uninitialised), calloc(n,size) (zero-initialised), realloc resizes, free releases. Memory leak = allocated but never freed.
  • Recursion: a function calling itself; needs a base case. Factorial: f(n) = n × f(n−1), f(0)=1.
  • struct groups different types; union shares one memory for all members (size = largest member).
#include <stdio.h>
int main() {
    int a[] = {1, 2, 3}, *p = a;
    printf("%d %d", *p, *(p + 2));   // output: 1 3
    return 0;
}
Tip: 5/2 → 2, −5/2 → −2 (truncates toward zero); x++ uses then increments, ++x increments then uses.
सुझाव: x++ पहले उपयोग, फिर बढ़ोतरी; ++x पहले बढ़ोतरी, फिर उपयोग।

4. Data Structures / डेटा स्ट्रक्चर

StructureKey points / मुख्य बिंदु
ArrayFixed size, contiguous memory, O(1) access by index.
Linked listNodes with data + pointer; dynamic size; insertion/deletion O(1) at known position; access O(n). Types: singly, doubly, circular.
StackLIFO (Last In First Out); push, pop, peek. Uses: function calls, undo, expression evaluation, DFS.
QueueFIFO; enqueue, dequeue. Types: circular, deque, priority queue. Uses: scheduling, BFS.
TreeNon-linear hierarchical structure. Root, parent, child, leaf, height.
GraphVertices + edges; non-linear. Stored as adjacency matrix or adjacency list.
Hash tableKey → index by hash function; average O(1) search, insert, delete. Collisions: chaining, open addressing.
  • Linear: array, list, stack, queue. Non-linear: tree, graph. रैखिक: ऐरे, लिस्ट, स्टैक, क्यू; गैर-रैखिक: ट्री, ग्राफ।
  • Binary tree: max 2 children per node. Max nodes at level i = 2i; max nodes in height h = 2h+1−1.
  • BST: left < root < right. Inorder traversal of BST gives sorted order. Number of distinct BSTs with n keys = Catalan number: n=3 → 5, n=4 → 14.
  • Traversals: Inorder (L-Root-R), Preorder (Root-L-R), Postorder (L-R-Root). BFS uses a queue (level order); DFS uses a stack.
  • Balanced tree (AVL): height difference of the two subtrees of any node ≤ 1. Heap: complete binary tree; max-heap parent ≥ children.
  • Spanning tree of a graph with N vertices has N−1 edges. Complete graph has N(N−1)/2 edges.
  • Postfix: operands first, then operator. Evaluate with stack. Example: 10 5 + → 15; 60 6 / → 10; then 15 10 * → 150.
  • Infix to postfix: A+B*C → ABC*+ ; prefix: +A*BC.

  • Big-O = upper bound (worst case); Omega (Ω) = lower bound; Theta (Θ) = tight bound. बिग-ओ ऊपरी सीमा दर्शाता है।
  • Order: O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!).

  • Graph traversal: BFS and DFS. Shortest path: Dijkstra, Bellman-Ford, Floyd-Warshall. Minimum spanning tree: Prim, Kruskal.
  • Binary search on n elements needs at most ⌊log₂ n⌋+1 comparisons.

6. Operating System / ऑपरेटिंग सिस्टम

  • OS = interface between user and hardware; manages process, memory, file, I/O. Types: batch, multiprogramming, time-sharing, real-time, distributed, network, embedded, mobile. OS उपयोगकर्ता और हार्डवेयर के बीच इंटरफेस है।
  • Process states: New → Ready → Running → Waiting/Blocked → Terminated. PCB (Process Control Block) stores process information.
  • Process vs thread: thread is a lightweight process sharing code, data and files of its process but with its own stack and registers.

CPU scheduling / सीपीयू शेड्यूलिंग

  • FCFS (non-preemptive, convoy effect), SJF (minimum average waiting time; may starve), Priority (starvation → solved by aging), Round Robin (time quantum; preemptive; good for time-sharing).
  • Turnaround time = Completion − Arrival; Waiting time = Turnaround − Burst.

Deadlock / डेडलॉक

  • Four necessary conditions (all must hold): Mutual exclusion, Hold and wait, No preemption, Circular wait.
  • Handling: prevention, avoidance (Banker's algorithm), detection and recovery, ignore (ostrich).
  • Semaphore: integer variable with wait(P) and signal(V); binary semaphore (0/1) and counting semaphore. Critical section problem: mutual exclusion, progress, bounded waiting.

Memory management / मेमोरी प्रबंधन

  • Paging: physical memory divided into fixed-size frames, logical memory into pages of same size; no external fragmentation (internal fragmentation possible). पेजिंग: निश्चित आकार के पेज और फ्रेम।
  • Segmentation: variable-size logical segments (code, data, stack); segment table holds base and limit.
  • Virtual memory: demand paging; page fault when needed page is not in RAM. Thrashing = excessive paging, CPU spends more time swapping than executing.
  • Page replacement: FIFO (Belady's anomaly), LRU, Optimal.
  • Page offset bits = log₂(page size). Page size 4 KB = 212 → 12 offset bits.
  • Allocation: first fit, best fit, worst fit. External fragmentation (free space scattered) vs internal (wasted inside allocated block).

File systems / फाइल सिस्टम

  • Windows: FAT32, NTFS, exFAT. Linux: ext3/ext4. macOS: HFS+/APFS. File operations: create, open, read, write, delete, rename, seek.
  • Common Linux commands: ls, cd, pwd, mkdir, rm, cp, mv, cat, chmod, grep, ps, kill.

7. DBMS & SQL / डेटाबेस और SQL

  • DBMS manages a database; examples: MySQL, Oracle, PostgreSQL, SQL Server, MS Access. Advantages: less redundancy, data integrity, security, sharing, backup.
  • Data models: hierarchical, network, relational (most used), object-oriented. ER model: entity, attribute, relationship; cardinality 1:1, 1:N, M:N.
  • Keys: Super key, Candidate key, Primary key (unique, not null), Alternate key, Foreign key (refers to primary key of another table), Composite key.
  • Degree = number of columns (attributes); Cardinality = number of rows (tuples). डिग्री = कॉलम की संख्या; कार्डिनैलिटी = पंक्तियों की संख्या।

CREATE TABLE student (roll INT PRIMARY KEY, name VARCHAR(30), marks INT);
INSERT INTO student VALUES (1, 'Rahul', 85);

  • Joins: INNER, LEFT, RIGHT, FULL OUTER, CROSS. DELETE removes rows (can rollback); TRUNCATE removes all rows (no rollback in most DBs); DROP removes the table itself.
  • ACID: Atomicity, Consistency, Isolation, Durability.

8. Computer Networks / कंप्यूटर नेटवर्क

  • Types: PAN, LAN (building), MAN (city), WAN (country; Internet is the largest WAN).
  • Topologies: Bus, Star (most common; central hub/switch), Ring, Mesh (n(n−1)/2 links), Tree, Hybrid.
  • Devices: Hub (broadcasts), Switch (uses MAC address), Router (uses IP address, connects networks), Bridge, Gateway, Modem, Repeater.

Memory trick / याद रखने की ट्रिक: Please Do Not Throw Sausage Pizza Away (1→7).

  • TCP/IP model has 4 layers: Application, Transport, Internet, Network access.
  • TCP: reliable, connection-oriented. UDP: unreliable, connectionless, faster (video streaming).
  • IPv4 = 32-bit (e.g., 192.168.1.1), IPv6 = 128-bit. MAC address = 48-bit physical address.
  • IP classes: A (1–126), B (128–191), C (192–223), D (multicast 224–239), E (reserved).
  • Ports: HTTP 80, HTTPS 443, FTP 21, SSH 22, SMTP 25, DNS 53, POP3 110, Telnet 23.
  • DNS converts domain names to IP address. DHCP assigns IP automatically. ARP maps IP → MAC.
  • Transmission modes: simplex (one way), half duplex (both ways, one at a time), full duplex (both ways at once).
  • Media: twisted pair, coaxial, optical fibre (fastest, no EMI), wireless (Wi-Fi, Bluetooth, microwave).

9. Internet, Web & Security / इंटरनेट, वेब और सुरक्षा

  • WWW invented by Tim Berners-Lee (1989–91). Browser examples: Chrome, Firefox, Edge. URL = protocol + domain + path.
  • HTML = markup language for web pages; tags: <h1>–<h6>, <p>, <a href>, <img src>, <table>, <ul>/<ol>, <form>. CSS styles the page; JavaScript adds behaviour. HTML वेब पेज की संरचना बनाती है, CSS सजावट, JavaScript व्यवहार।
  • Email: SMTP sends; POP3/IMAP receive. To, Cc, Bcc (hidden recipients).
  • Security threats: virus, worm (self-replicating), trojan (disguised), ransomware, spyware, phishing (fake emails/sites), spoofing, DoS/DDoS, man-in-the-middle.
  • Protection: antivirus, firewall, strong passwords, two-factor authentication, encryption (symmetric: one key – AES/DES; asymmetric: public + private key – RSA), digital signature, HTTPS/SSL/TLS.
  • Cyber crime law in India: IT Act 2000. E-commerce, UPI, digital India, e-governance, cloud computing (IaaS, PaaS, SaaS), IoT, AI, Big Data, blockchain – basic definitions are often asked.
  • MS Office shortcuts: Ctrl+C copy, Ctrl+X cut, Ctrl+V paste, Ctrl+Z undo, Ctrl+Y redo, Ctrl+S save, Ctrl+P print, Ctrl+A select all, Ctrl+B/I/U bold/italic/underline, F12 Save As (Word). Excel: formulas start with "=", e.g. =SUM(A1:A5), =AVERAGE(), =IF(), =VLOOKUP(); cell reference A1; extension .xlsx; Word .docx; PowerPoint .pptx.

10. OOP, C++ & Python / ओओपी, C++ और पाइथन

  • OOP pillars: Encapsulation (data hiding in class), Abstraction, Inheritance (reuse; single, multiple, multilevel, hierarchical, hybrid), Polymorphism (compile-time: overloading; run-time: overriding, virtual function).
  • C++ was created by Bjarne Stroustrup. Class members default to private (struct → public). Constructor has the same name as the class, no return type; destructor uses ~ClassName. Access specifiers: private, protected, public.
  • Java: platform independent via bytecode and JVM; no pointers; garbage collection. Developed by James Gosling at Sun.

Python basics

  • Interpreted, dynamically typed, indentation defines blocks. Created by Guido van Rossum. Comments start with #.
  • Data types: int, float, str, bool, list [ ] (mutable), tuple ( ) (immutable), set { } (unique), dict {key: value}.
  • Loops: for i in range(5) → 0..4; while; break/continue. Functions: def f(x): return x*2.
nums = [1, 2, 3, 4]
print(nums[-1])            # 4
print(nums[1:3])           # [2, 3]
print([x*x for x in nums]) # [1, 4, 9, 16]
d = {"a": 1}; d["b"] = 2
print(len(d))              # 2
print(10 // 3, 10 % 3, 2 ** 3)   # 3 1 8
